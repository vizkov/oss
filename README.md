A methodology I came up with for doing security research and secure code review. It integrates [Comment Anchors](https://marketplace.visualstudio.com/items?itemName=ExodiusStudios.comment-anchors) (for visualization/navigation), **VS Code Snippets** (for automation) and git to create a structured, professional auditing environment.

Note: There is a known bug which causes rendering issues in [Comment Anchors plugin](https://github.com/StarlaneStudios/vscode-comment-anchors/issues/139) / [PR](https://github.com/StarlaneStudios/vscode-comment-anchors/pull/243)
